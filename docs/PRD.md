# Product Requirements Document
## Mental Health Platform — Psychologist App

**Version:** 1.0
**Status:** Draft

## 1. Problem Statement

### Боль пользователя

**Для клиентов:**
Люди, нуждающиеся в психологической помощи, сталкиваются с тремя ключевыми барьерами:
1. **Непрозрачность рынка** — сложно найти подходящего специалиста: нет верифицированных отзывов, непонятна квалификация, нельзя быстро сравнить психологов.
2. **Организационная трудность** — запись через мессенджеры, звонки, ручное согласование времени; нет единого места для управления сессиями.
3. **Стигма и барьер входа** — первый шаг к психологу психологически тяжёл; нужен безопасный, приватный и удобный цифровой интерфейс.

**Для психологов:**
1. **Операционная нагрузка** — расписание в таблицах, оплата через переводы, учёт клиентов вручную.
2. **Отсутствие доверия со стороны клиентов** — нет инструмента для подтверждения квалификации и накопления репутации.
3. **Низкая заполняемость** — сложно привлекать новых клиентов без маркетинговых вложений.

> *Подтверждение: глубинные интервью с 12 клиентами и 8 психологами (Q1 2026). Ключевые инсайты: 9/12 клиентов называли «непонятно как выбрать психолога» как главный барьер; 7/8 психологов тратят >3 часов в неделю на административные задачи.*

## 3. Value Proposition

### Для клиента
> «Найди проверенного психолога, запишись за 2 минуты и проводи сессии — всё в одном приложении.»

- Верифицированные специалисты с реальными отзывами
- Прозрачное расписание и онлайн-запись без звонков
- Безопасная оплата с гарантией возврата при отмене
- Видеосессии и чат в одном интерфейсе

### Для психолога
> «Фокусируйся на клиентах — приложение берёт на себя расписание, оплату и репутацию.»

- Автоматический сбор оплаты и выплаты
- Профиль с верификацией и рейтингом как инструмент доверия
- Аналитика дохода и загруженности
- Личные заметки о клиентах (видны только психологу)

### Конкурентные преимущества

| Критерий | Наш продукт | YouTalk | Zigmund.online |
|---|---|---|---|
| Верификация дипломов | Да | Частично | Да |
| Групповые сессии | Да | Нет | Нет |
| Нативное мобильное приложение | Да (iOS + Android) | Нет | Нет |
| Заметки психолога | Да | Нет | Нет |
| СБП оплата | Да | Нет | Нет |

## 4. MVP Scope

### Must Have — Функции первого запуска

#### Аутентификация и профиль
- [ ] Регистрация/вход через email + OTP-код *(реализовано)*
- [ ] Разделение ролей: клиент / психолог *(реализовано)*
- [ ] Профиль клиента: фото, имя, анкета *(реализовано)*
- [ ] Профиль психолога: фото, специализация, стоимость, описание *(реализовано)*

#### Каталог и поиск
- [ ] Список психологов с базовыми фильтрами *(реализовано)*
- [ ] Добавление в избранное *(реализовано)*
- [ ] Страница профиля психолога

#### Расписание и запись
- [ ] Психолог задаёт слоты доступности
- [ ] Клиент видит свободное время и бронирует слот
- [ ] Отмена/перенос записи клиентом и психологом
- [ ] Push-уведомления о записи (за 24ч и 1ч)

#### Сессии
- [ ] Видеозвонок (LiveKit) *(реализовано)*
- [ ] Чат в реальном времени (WebSocket) *(реализовано)*
- [ ] Групповые сессии *(реализовано)*

#### Оплата
- [ ] Интеграция с ЮKassa (банковские карты, СБП)
- [ ] Оплата при бронировании сессии
- [ ] История платежей
- [ ] Рефанд при отмене за ≥24 часа до сессии

#### Верификация психолога
- [ ] Загрузка диплома/сертификатов
- [ ] Ручная модерация администратором
- [ ] Статус «Проверен платформой» на профиле

#### Рейтинги и отзывы
- [ ] Клиент оставляет оценку и текстовый отзыв после сессии
- [ ] Рейтинг психолога (средняя оценка) влияет на позицию в каталоге
- [ ] Модерация отзывов администратором

#### Личный кабинет психолога
- [ ] Аналитика: доход за период, количество сессий, текущий рейтинг
- [ ] Управление расписанием (слоты, рабочие часы)
- [ ] Список клиентов с историей сессий
- [ ] Приватные заметки о клиенте после сессии

#### Медитации
- [ ] Каталог медитаций с аудио *(реализовано)*

## 6. User Stories

### Клиент

```
US-01: Как клиент, я хочу войти через email без пароля (OTP),
       чтобы не помнить пароль и сразу начать работу.

US-02: Как клиент, я хочу видеть список верифицированных психологов
       с рейтингом и специализацией, чтобы выбрать подходящего.

US-03: Как клиент, я хочу видеть доступные слоты психолога в календаре,
       чтобы записаться без созвона в удобное для меня время.

US-04: Как клиент, я хочу оплатить сессию картой или СБП,
       чтобы не переводить деньги вручную.

US-05: Как клиент, я хочу получить возврат при отмене за 24+ часа,
       чтобы не терять деньги при форс-мажоре.

US-06: Как клиент, я хочу провести видеосессию прямо в приложении,
       чтобы не переходить в Zoom или другие сервисы.

US-07: Как клиент, я хочу оставить отзыв после сессии,
       чтобы помочь другим выбрать специалиста.

US-08: Как клиент, я хочу добавить психолога в избранное,
       чтобы быстро записаться повторно.

US-09: Как клиент, я хочу слушать медитации в приложении,
       чтобы практиковать самопомощь между сессиями.
```

### Психолог

```
US-10: Как психолог, я хочу задать слоты доступности на неделю,
       чтобы клиенты видели только реально свободное время.

US-11: Как психолог, я хочу загрузить диплом для верификации,
       чтобы получить значок «Проверен» и повысить доверие клиентов.

US-12: Как психолог, я хочу видеть аналитику дохода и количества сессий,
       чтобы планировать загруженность и финансы.

US-13: Как психолог, я хочу оставлять приватные заметки о клиенте,
       чтобы помнить контекст между сессиями (видно только мне).

US-14: Как психолог, я хочу видеть рейтинг и отзывы на моём профиле,
       чтобы получать обратную связь и привлекать новых клиентов.
```

### Администратор

```
US-15: Как администратор, я хочу модерировать документы психологов,
       чтобы присваивать статус «Проверен» только квалифицированным.

US-16: Как администратор, я хочу модерировать отзывы клиентов,
       чтобы удалять спам и неэтичный контент.

US-17: Как администратор, я хочу управлять пользователями платформы,
       чтобы обрабатывать жалобы и блокировать нарушителей.
```

## 7. Non-Functional Requirements

### Производительность

| Метрика | Цель |
|---|---|
| Время отклика API (p95) | < 200 мс для CRUD-операций |
| Время отклика API (p95) для поиска | < 500 мс |
| Пропускная способность | 100 RPS (базовый MVP) |
| Доступность | 99.5% uptime (≤ 3.65 ч даунтайма в месяц) |
| Задержка WebSocket-сообщений | < 100 мс в рамках одного региона |

### Безопасность

| Требование | Реализация |
|---|---|
| Аутентификация | JWT HS256, истечение токена через `TOKEN_EXPIRE_DAYS` |
| Авторизация | Role-based: client / psychologist / admin |
| Валидация входных данных | Pydantic схемы на всех эндпоинтах |
| Защита платёжных данных | Данные карт не хранятся на сервере (токенизация через ЮKassa) |
| HTTPS | TLS 1.2+ обязательно на всех эндпоинтах |
| Приватность заметок | Заметки психолога не возвращаются в клиентских эндпоинтах |
| Rate limiting | 60 запросов/мин на IP для публичных эндпоинтов |

### Масштабируемость

- Горизонтальное масштабирование backend (stateless FastAPI + Redis для сессий)
- Индексы PostgreSQL на часто запрашиваемых полях (psychologist_id, user_id, created_at)
- CDN для медиафайлов (аватары, материалы медитаций, документы верификации)

### Совместимость

| Платформа | Минимальная версия |
|---|---|
| iOS | 16.0+ |
| Android | 10 (API 29)+ |
| Web (frontend-web) | Современные браузеры (Chrome 100+, Safari 15+) |

## 10. Риски и митигация

| Риск | Вероятность | Митигация |
|---|---|---|
| Низкое число психологов при запуске | Высокая | Ручной онбординг первых 20–30 специалистов |
| Проблемы с верификацией документов | Средняя | Временный ручной процесс через email |
| Технические сбои во время видеосессии | Средняя | Мониторинг LiveKit, fallback на чат |
| Мошеннические отзывы | Низкая | Отзыв только после завершённой оплаченной сессии |
| Регуляторные ограничения (мед. лицензия) | Средняя | Консультация юриста; позиционирование как «психологическая помощь», не медицина |
